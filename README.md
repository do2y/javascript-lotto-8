# 🎰 로또 발매기

_3주차 우아한테크코스 프리코스 미션_
<br>

> 간단한 로또 발매기입니다. <br>
> 사용자가 로또 구입 금액을 입력하면 금액에 해당하는 만큼의 로또를 발행합니다. <br>
> 이후 당첨 번호와 보너스 번호를 입력받아 발행된 로또와 비교한 뒤 당첨 내역 및 수익률을 출력하고 게임을 종료합니다.

<br>

## 프로그래밍 요구사항

```text
- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
- 3항 연산자를 쓰지 않는다.
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.
- Jest를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.

- 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
- else를 지양한다.
- 구현한 기능에 대한 단위 테스트를 작성한다. 단, UI(System.out, System.in, Scanner) 로직은 제외한다.
- @woowacourse/mission-utils에서 제공하는 Random 및 Console API를 사용하여 구현해야 한다.
- 제공된 Lotto 클래스를 사용하여 구현해야 한다.
```

<br>

## 구현 기능 목록

- [x] **로또 구입 금액 입력 처리**
  - [x] 사용자로부터 로또 구입 금액을 입력 받는다. <br>
        ex) `'14000'`
  - [x] 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.

- [x] **당첨 번호 입력 처리**
  - [x] 번호는 쉼표(`,`)를 기준으로 구분한다. <br>
        ex) `'1,2,3,4,5,6'`
  - [x] 보너스 번호를 입력 받는다.  
         ex) `7`

- [x] **당첨 번호 파싱 및 검증**
  - [x] 입력된 당첨 번호 문자열을 쉼표(`,`)를 기준으로 분리한다.
  - [x] 분리된 각 값이 숫자인지 검증한다.

- [x] **로또 번호 생성**
  - [x] 구입 금액에 따라 n개의 로또를 발행한다.
  - [x] 1~45 사이의 중복되지 않는 6개 숫자를 랜덤으로 생성한다.
  - [x] 각 로또 번호를 오름차순으로 정렬한다.

- [x] **로또 수량 및 번호 출력**
  - [x] 발행한 로또 수량 및 번호를 출력한다.
  - [x] 오름차순 정렬된 로또 번호를 보여준다.

- [x] **당첨 결과 계산**
  - [x] 각 로또의 번호와 당첨 번호를 비교한다.
  - [x] 일치 개수 및 보너스 번호 일치 여부를 판정한다.
  - [x] 일치 결과에 따라 등수(1~5등)를 결정한다.

- [x] **당첨 통계 출력**
  - [x] 당첨 통계를 출력한다.

- [x] **수익률 계산**
  - [x] 당첨 결과에 따른 총 상금을 계산한다.
  - [x] 수익률을 계산하고 소수점 둘째 자리에서 반올림한다. <br>
        ex) `100.0%`, `51.5%`

- [x] **수익률 출력**
  - [x] 소수점 둘째 자리에서 반올림한 수익률을 출력한다.

- [x] **예외 처리 및 재입력**
  - [x] 잘못된 입력 시 `[ERROR]`로 시작하는 메시지를 출력한다.
  - [x] 에러가 발생한 입력 단계부터 다시 입력받는다.

<br>

## 예외

- [x] **금액 입력 예외**
  - [x] 1,000원으로 나누어 떨어지지 않는 경우
  - [x] 정수가 아닌 경우 (문자, 소수 등)
- [x] **당첨 번호 입력 예외**
  - [x] 1~45 사이 범위 외의 값을 입력
  - [x] 정수가 아닌 값 입력 (문자/소수 등)
  - [x] 중복된 번호 입력
- [x] **보너스 번호 입력 예외**
  - [x] 당첨 번호와 중복된 경우
  - [x] 정수가 아닌 값 입력 (문자/소수 등)

<br>
